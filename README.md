### Adarsh V H
Third-year CSE student at JSS Bengaluru. I build software across the systems and backend stack, with a particular interest in performance, databases, distributed systems, and cloud infrastructure.

I like understanding what happens underneath the abstractions: how data moves through a system, how databases execute and store data, where latency comes from, how services communicate, and how software ultimately interacts with the hardware beneath it.

---

**What I'm built so far**

- [Agentic-KSP](https://github.com/adarsh-v-h/AgenticAI-KSP) — An agentic crime-intelligence platform connecting natural-language interaction with secure database intelligence. FastAPI, gRPC, MySQL, AWS RDS, SSE, RAG, authentication and query validation.

- [Universal Log Framework (ULPF)](https://github.com/adarsh-v-h/ULPF) — A universal log ingestion and normalization framework for heterogeneous vendor and application sources, preserving raw events while transforming them into a common schema. Java, Spring Boot, SQLite, ClickHouse, Podman, schema mapping and integrity verification.

- [High-Performance Limit Order Book](https://github.com/adarsh-v-h/Order_book) — An evolving C++ matching engine focused on low-latency execution, cache-aware data structures, concurrency, memory layout and deterministic hot paths.(Still long way to go)

- [Themis's Domain — CRMS](https://github.com/adarsh-v-h/Crime_DB) — A crime record management system built around relational data, backend services, authentication, authorization, indexing, connection pooling, caching and secure workflows.(Mostly vibe-coded)

- [navexa ARMv8-A Library](https://github.com/adarsh-v-h/navexa_ARMv8-A_Library) — A low-level C++ library exploring ARMv8-A architectural features through NEON intrinsics, AArch64 inline assembly, SVE emulation, LSE atomics and memory tagging. Cross-compiled and tested through QEMU.

- [Software-Defined FADEC Simulation](https://github.com/adarsh-v-h/Software-Defined-FADEC-Simulation) — A C++ simulation of a fault-tolerant FADEC architecture with closed-loop engine dynamics, control systems, telemetry and safe-state failover.
